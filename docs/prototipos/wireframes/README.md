# Wireframes — adote.anim

## 1. Objetivo

Os wireframes representam a **estrutura visual inicial das principais telas do adote.anim**, servindo como base para organizar os elementos da interface antes da aplicação completa da identidade visual.

A proposta busca estabelecer uma experiência de navegação **simples, clara, intuitiva e responsiva**, mantendo consistência entre as diferentes telas da plataforma.

## 2. Estrutura de navegação

A navegação pública do adote.anim será composta pelas seguintes opções:

- **Início**
- **Sobre**
- **Como funciona**
- **Encontrar um pet**
- **Avaliações**
- **Entrar**
- **Quero adotar**

A opção **Quero adotar** terá maior destaque visual por representar uma das principais ações da plataforma, direcionando o usuário para a área de descoberta e busca por animais.

A navegação deverá manter uma estrutura simples e de fácil compreensão, permitindo que o usuário encontre rapidamente as principais áreas do site.

## 3. Tela inicial

A página inicial será responsável por apresentar a proposta do **adote.anim** e direcionar o usuário para as principais ações da plataforma.

### Elementos previstos

- Cabeçalho com logotipo e menu de navegação;
- Seção principal de apresentação (*hero*);
- Chamada para encontrar um animal;
- Apresentação da proposta da plataforma;
- Destaques relacionados à adoção;
- Elementos visuais relacionados aos animais;
- Rodapé com informações complementares.

A composição deverá utilizar uma hierarquia visual clara, destacando principalmente a ação de **encontrar um pet**.

## 4. Tela "Encontrar um pet"

A tela de busca será destinada à visualização e descoberta dos animais disponíveis.

### Elementos previstos

- Título da página;
- Campo de busca;
- Filtros de pesquisa;
- Cards dos animais;
- Fotografia do animal;
- Informações básicas;
- Ação para acessar a ficha completa.

Os cards deverão seguir um **padrão visual consistente**, mantendo proporções, espaçamentos e hierarquia de informações semelhantes, independentemente da espécie do animal apresentado.

A interface deverá contemplar diferentes espécies, evitando que o layout seja visualmente limitado apenas a cães e gatos.

## 5. Ficha do animal

A ficha do animal apresentará as principais informações necessárias para que o usuário conheça o pet.

### Informações apresentadas

- **Fotografia**
- **Nome**
- **Espécie**
- **Raça ou tipo**, quando aplicável
- **Idade**
- **Porte**
- **Localização**
- **Status de adoção**
- **Descrição e personalidade**
- **Informações de saúde**
- **Vacinas**
- **Consultas**
- **Responsável**

A tela deverá apresentar também a ação principal:

> **Tenho interesse em adotar**

Essa ação deverá possuir destaque visual adequado, facilitando sua identificação pelo usuário.

## 6. Tela de cadastro de animal

A tela de cadastro deverá apresentar um formulário organizado para inserção das informações do animal.

Os campos serão distribuídos de maneira lógica, facilitando o preenchimento e evitando uma apresentação visual excessivamente carregada.

### Informações previstas

- Dados gerais do animal;
- Características;
- Localização;
- Imagem;
- Informações relacionadas à saúde;
- Dados complementares.

A estrutura deverá seguir os mesmos padrões visuais utilizados nas demais telas do sistema.

## 7. Tela de cadastro de tutor

A tela de cadastro de tutor deverá apresentar um formulário organizado e visualmente consistente com a identidade do **adote.anim**.

O formulário deverá utilizar:

- Campos organizados por grupos de informações;
- Hierarquia visual clara;
- Espaçamento adequado;
- Botões de ação destacados;
- Componentes consistentes com as demais telas.

## 8. Tela de saúde e vacinas

A tela de saúde será destinada à organização das informações relacionadas aos cuidados do animal.

### Informações previstas

- **Vacinas**
- **Consultas**
- **Datas**
- **Informações complementares**

A apresentação deverá priorizar a **leitura rápida e a organização das informações**, utilizando componentes visuais que facilitem a identificação dos dados mais importantes.

## 9. Responsividade

Os wireframes deverão considerar diferentes tamanhos de tela, garantindo que a estrutura visual possa ser adaptada para diferentes dispositivos.

### Desktop

A versão **desktop** será utilizada como referência principal para a construção inicial da interface, recebendo o maior nível de detalhamento visual.

### Mobile

Posteriormente, a estrutura será adaptada para dispositivos móveis, considerando:

- Menu compacto;
- Reorganização dos componentes;
- Ajuste de tamanhos;
- Adequação dos espaçamentos;
- Redimensionamento de imagens e cards;
- Preservação das principais ações da interface.

O objetivo é manter a identidade visual e a facilidade de navegação independentemente do dispositivo utilizado.

## 10. Diretrizes gerais

Os wireframes deverão seguir um conjunto de princípios visuais para garantir consistência entre as telas.

### Princípios

- **Hierarquia visual clara**
- **Consistência entre telas**
- **Espaçamentos padronizados**
- **Componentes reutilizáveis**
- **Destaque adequado para ações principais**
- **Navegação simples e intuitiva**
- **Boa organização das informações**
- **Adaptação para diferentes tamanhos de tela**
- **Uso consistente da identidade visual**
- **Experiência acolhedora e profissional**

## 11. Direção visual

Os wireframes servirão como base para a aplicação da identidade visual definida para o **adote.anim**.

A interface deverá combinar uma aparência **moderna e profissional** com elementos visuais que transmitam **acolhimento, proximidade e cuidado com os animais**.

A aplicação posterior da identidade visual deverá manter:

- Paleta de cores definida;
- Tipografia **Inter**;
- Padrão de componentes;
- Arredondamento e espaçamentos consistentes;
- Uso adequado de imagens;
- Hierarquia visual entre títulos, textos e ações.

> **Resultado esperado:** uma estrutura visual organizada que facilite a transformação dos wireframes em um protótipo de alta fidelidade, mantendo uma experiência consistente em todas as telas do adote.anim.
