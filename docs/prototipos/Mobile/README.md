# Protótipo Mobile — Adote.anim

## 1. Objetivo

O protótipo mobile tem como objetivo adaptar a identidade visual e a estrutura de navegação do **adote.anim** para dispositivos com telas menores, mantendo a clareza das informações, a facilidade de uso e a consistência visual estabelecida na versão desktop.

A adaptação considera diferentes tamanhos de tela e prioriza a organização dos conteúdos e a acessibilidade das principais ações da interface.

## 2. Adaptação da interface

Na versão mobile, os componentes da interface são reorganizados de forma a utilizar melhor o espaço disponível e facilitar a navegação por dispositivos com interação por toque.

As principais adaptações incluem:

- menu de navegação em formato compacto;
- organização vertical dos conteúdos;
- adaptação dos cards à largura da tela;
- reorganização dos campos e elementos dos formulários;
- dimensionamento adequado dos botões para interação por toque;
- redução ou reorganização de elementos secundários quando necessário;
- ajuste de espaçamentos e hierarquia das informações.

## 3. Navegação

O menu principal da versão mobile será apresentado de forma compacta, utilizando um **menu do tipo hamburger**.

Essa abordagem permite preservar o acesso às principais áreas da aplicação sem ocupar uma área excessiva da tela, mantendo o foco no conteúdo apresentado.

A navegação deve seguir a mesma lógica definida para a versão desktop, adaptando apenas sua disposição e apresentação para o contexto mobile.

## 4. Telas

O protótipo mobile contempla as principais telas definidas para o projeto:

- página inicial;
- encontrar um pet;
- ficha do animal;
- cadastro de animal;
- cadastro de tutor;
- saúde e vacinas.

As telas mantêm a estrutura e as informações essenciais definidas no protótipo desktop, realizando apenas as adaptações necessárias para o formato mobile.

## 5. Consistência visual

A versão mobile preserva os principais elementos da identidade visual do **adote.anim**, garantindo continuidade entre as diferentes versões da interface.

São mantidos:

- logotipo e assinatura visual;
- tipografia **Inter**;
- paleta oficial de cores;
- estilos dos botões;
- componentes de cards;
- elementos com cantos arredondados;
- hierarquia visual das informações;
- padrões de espaçamento e organização;
- linguagem visual geral do projeto.

A adaptação responsiva deve modificar a disposição e o dimensionamento dos elementos conforme o espaço disponível, sem descaracterizar a identidade visual definida para o **adote.anim**.
