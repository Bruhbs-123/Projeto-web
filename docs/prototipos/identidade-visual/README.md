# Identidade Visual — adote.anim

> **Adoção com informação. Cuidado com propósito.**

Este documento apresenta a identidade visual definida para o **adote.anim**, incluindo conceito, logotipo, tipografia, paleta de cores e diretrizes de aplicação da interface.

## 1. Nome da plataforma

### **adote.anim**

O nome **adote.anim** representa a proposta de aproximar pessoas interessadas em adoção de animais, reunindo informações de forma simples, clara e acolhedora.

A identidade foi pensada para transmitir uma experiência que combine **tecnologia, cuidado e proximidade**, mantendo uma aparência moderna e profissional.

## 2. Conceito visual

A identidade visual do **adote.anim** foi desenvolvida para transmitir os seguintes valores:

- 🐾 **Acolhimento**
- 🤝 **Confiança**
- ❤️ **Proximidade**
- 🌱 **Cuidado**
- 🐶 **Diversidade**
- 🏡 **Responsabilidade**

A proposta combina elementos relacionados ao universo dos animais com uma interface moderna, organizada e de fácil compreensão.

O objetivo é criar uma experiência visual acolhedora sem utilizar uma estética excessivamente infantil, permitindo que a plataforma mantenha uma aparência profissional e acessível.

## 3. Logotipo

O logotipo do **adote.anim** utiliza uma composição circular formada por diferentes animais integrados entre si.

A representação dos animais dentro do mesmo símbolo busca transmitir os conceitos de:

- **diversidade**, pela presença de diferentes espécies;
- **união**, pela integração dos elementos;
- **comunidade**, representando a conexão entre animais e pessoas;
- **acolhimento**, reforçando a proposta de adoção responsável.

O nome **adote.anim** acompanha o símbolo como identificação principal da plataforma.

### Conceito do símbolo

> **Diferentes animais, uma mesma causa.**

## 4. Tipografia

### Fonte principal: **Inter**

A família tipográfica **Inter** foi escolhida como fonte principal da interface por apresentar:

- excelente legibilidade;
- aparência moderna;
- boa adaptação a diferentes tamanhos de tela;
- consistência entre títulos, textos e elementos de interface;
- boa aplicação em interfaces digitais.

A tipografia será utilizada de forma consistente em títulos, subtítulos, textos, botões, formulários e demais componentes da plataforma.

### Hierarquia tipográfica

A interface utiliza diferentes pesos da fonte para estabelecer uma hierarquia visual clara:

| Elemento | Aplicação |
|---|---|
| Títulos | Destaque e identificação das seções |
| Subtítulos | Organização e contextualização do conteúdo |
| Texto | Informações e descrições |
| Botões | Ações principais e secundárias |
| Labels | Identificação de campos e informações |

## 5. Paleta de cores

A paleta do **adote.anim** combina tons quentes, naturais e neutros.

Os tons de laranja e amarelo reforçam energia, proximidade e acolhimento, enquanto os verdes representam natureza e cuidado. Os tons neutros são utilizados para manter equilíbrio, legibilidade e organização visual.

## 6. Direção visual

A interface do **adote.anim** segue uma direção visual **moderna, acolhedora e organizada**.

### Principais características

- uso de espaços em branco para facilitar a leitura;
- cards com cantos arredondados;
- imagens dos animais como elementos de destaque;
- hierarquia visual bem definida;
- botões com destaque adequado;
- utilização equilibrada das cores da identidade;
- componentes visuais consistentes;
- navegação simples e intuitiva.

A interface deve transmitir uma sensação de proximidade e cuidado, sem perder a característica de uma plataforma digital profissional.

## 7. Representação dos animais

A identidade visual considera a diversidade de espécies presentes na plataforma.

Entre os exemplos utilizados no protótipo estão:

- 🐶 Cachorros
- 🐱 Gatos
- 🐰 Coelhos
- 🐹 Hamsters
- 🐦 Aves
- 🐹 Porquinhos-da-índia

Os animais devem ser apresentados de forma visualmente equilibrada, mantendo proporções, espaçamentos e componentes consistentes independentemente da espécie.

A utilização de diferentes espécies reforça o conceito de **diversidade e inclusão dentro da plataforma**.

## 8. Aplicação da identidade

A identidade visual será aplicada nas principais telas desenvolvidas para o protótipo do **adote.anim**:

- Página inicial;
- Página "Sobre";
- Página "Como funciona";
- Busca de animais;
- Ficha do animal;
- Cadastro de animal;
- Cadastro de tutor;
- Informações de saúde e vacinas;
- Área de avaliações;
- Componentes de navegação;
- Formulários;
- Cards de animais;
- Versão responsiva para dispositivos móveis.

Todos os elementos devem manter a mesma linguagem visual para garantir consistência entre as diferentes telas.

## 9. Componentes visuais

A identidade será aplicada também aos componentes reutilizáveis da interface, como:

- cabeçalho;
- menu de navegação;
- botões;
- cards;
- campos de formulário;
- filtros;
- etiquetas de status;
- ícones;
- rodapé;
- elementos de destaque;
- mensagens e estados da interface.

A padronização desses componentes contribui para uma experiência mais consistente e facilita a evolução visual do projeto.

## 10. Responsividade

A identidade visual deve ser preservada em diferentes tamanhos de tela.

A versão **Desktop** será utilizada como referência principal para o desenvolvimento inicial da interface. Posteriormente, os componentes serão adaptados para telas menores, mantendo:

- legibilidade;
- hierarquia visual;
- espaçamento adequado;
- acessibilidade dos elementos;
- facilidade de navegação;
- consistência das cores e da tipografia.

## 11. Frase de identidade

> **Adoção com informação. Cuidado com propósito.**

A frase representa a proposta visual e conceitual do **adote.anim**, relacionando a adoção responsável ao acesso à informação e ao cuidado com os animais.
