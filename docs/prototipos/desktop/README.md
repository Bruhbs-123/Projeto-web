# Protótipo Desktop — adote.anim

## 1. Objetivo

O protótipo desktop apresenta a aplicação da identidade visual do **adote.anim** em uma interface destinada principalmente a computadores e notebooks.

A versão desktop serve como referência principal para organização dos elementos visuais e estrutura das telas.

## 2. Telas prototipadas

O protótipo contempla as seguintes telas:

- Identidade Visual;
- Início;
- Encontrar um pet;
- Ficha do animal;
- Cadastro de animal;
- Cadastro de tutor;
- Saúde e vacinas.

## 3. Direção visual

As telas utilizam a identidade visual definida para o **adote.anim**, incluindo:

- Tipografia **Inter**;
- Paleta de cores oficial;
- Cards com cantos arredondados;
- Imagens dos animais em destaque;
- Botões de ação bem definidos;
- Espaçamento consistente;
- Hierarquia visual clara.

## 4. Diversidade de animais

O protótipo utiliza diferentes espécies para demonstrar que a plataforma não é limitada a cães e gatos.

Entre os exemplos utilizados estão:

- Cães;
- Gatos;
- Coelhos;
- Hamsters;
- Aves;
- Porquinhos-da-índia.

Os cards mantêm o mesmo padrão visual independentemente da espécie.

## 5. Componentes visuais

Entre os principais componentes utilizados estão:

- Cabeçalho;
- Menu de navegação;
- Botões;
- Cards de animais;
- Campos de formulário;
- Filtros;
- Informações em destaque;
- Seções informativas;
- Rodapé.

## 6. Organização

Os arquivos visuais correspondentes ao protótipo desktop devem ser armazenados na pasta:

`docs/prototipos/desktop/`

A documentação visual deve manter os arquivos organizados e identificados de acordo com suas respectivas telas.
